## 十条演示评测用例

`sample-data/evaluation-cases.json` 提供 7 条资料内问题和 3 条资料外问题，字段包括期望决策、期望文件、答案关键词和期望名次。数据集用于展示以下错误分类：

- `not_retrieved`：期望文档未召回；
- `ranked_too_low`：召回但低于目标名次；
- `answer_omission`：答案缺少必要信息；
- `wrong_citation`：引用了非预期切片；
- `wrong_refusal`：应拒答却作答，或应作答却拒答；
- `none`：规则全部满足。

这十条是可导入的合成演示用例，不代表真实用户流量或线上准确率。

## 真实服务验收

2026-09-08 使用百炼 `qwen-plus` 和 `text-embedding-v4` 完成真实服务验收。验收命令：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/smoke.ps1
```

脚本实测通过以下链路：创建知识库、上传公开样例、文档切片与向量写入、资料内回答及引用校验、资料外问题返回 `insufficient_context`。Docker 中的前端、API 和 Qdrant 均可用。

在只包含三份中文公开样例的干净演示库中，以阈值 `0.70` 运行十条用例，结果为 **10 / 10 通过（100%）**：7 条资料内问题均回答且引用预期文件，3 条资料外问题均拒答。该结果只代表当前合成样例集，不外推为真实业务准确率。

另一次诊断运行在同时含中英文重复退款政策的知识库中得到 **7 / 10**。三个失败均为 `wrong_citation`：答案事实正确，但引用命中了语义重复的英文文件，而用例只允许中文文件。该结果保留为产品缺口证据，说明评测规则和重复文档治理需要区分“内容正确”与“指定来源正确”。
